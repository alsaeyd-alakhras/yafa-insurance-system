## قواعد العمل (إلزامية كل جلسة)

1. اقرأ `STATUS.md` ثم `docs/TRACKER.md` قبل أي شغل.
2. اشتغل على مهمة وحدة (N.X) — spec المهمة في `docs/phases/phase-N-*/NN-task.md`.
3. لا تلمس ملفات خارج قسم "ملفات تتأثر" في الـ spec.
4. بعد كل مهمة: ✅ في TRACKER + حدّث STATUS.md.
5. قرار تقني جديد أو تراجع عن قرار → سجّله في `DECISIONS.md`. لا تقترح حلاً مرفوضاً فيه.
6. feature غير مطلوب بالـ spec → اقترحه في `docs/future-enhancements.md`، لا تنفذه.
