# yafa-insurance-system — وثيقة تحليل النظام

هذا المجلد يحتوي على وثيقة تحليل النظام الكاملة (System Analysis) لنظام بطاقات التأمين الطبي لمؤسسة يافا، قبل البدء بأي تصميم قاعدة بيانات أو برمجة.

## ترتيب القراءة الموصى به

1. **00-overview.md** — نطاق المشروع، الأهداف، المستخدمون، الافتراضات العامة.
2. **01-entities.md** — الكيانات كاملة: الحقول، الأنواع، العلاقات، مخطط العلاقات النصي.
3. **02-roles-permissions.md** — الأدوار (Admin / Receptionist) ومصفوفة الصلاحيات.
4. **03-business-rules.md** — قواعد العمل الحاكمة: الحصة الشهرية، منع الازدواجية، الخصومات، التابعين، الاستبيان، السجل.
5. **04-workflows.md** — تدفقات العمل التفصيلية (Diagrams نصية) لكل عملية رئيسية.
6. **05-use-cases.md** — حالات الاستخدام مفصّلة لكل دور.

## سياق مهم لأي عمل برمجي على هذا المشروع

- **الستاك:** Laravel + MySQL (Backend)، Blade/Tailwind أو حسب ما يُحدَّد لاحقاً (Frontend).
- **لا يوجد تقارير (Reporting) في هذه المرحلة** — البنية مصمَّمة لتسمح بإضافتها لاحقاً بسهولة، لكنها خارج النطاق الحالي.
- **الهيكل التنظيمي** (مركز/دائرة/قسم) بيانات فعلية موجودة مسبقاً بـ 3 جداول قديمة، وستُستورد وتُعاد هيكلتها كجدول شجري واحد (`organization_units`, self-referencing).
- **الخصومات على مستوى القسم الطبي وليس الموظف** — أي تغيير من الإدارة يُطبَّق فقط على الزيارات الجديدة (بحكم آلية الـ snapshot).
- **الرصيد الشهري (2 زيارة) لا يتراكم** ويُصفَّر تلقائياً كل شهر ميلادي.
- **وحدة الزيارة = مريض واحد + يوم واحد** — هذا هو المنطق الأهم في كامل النظام ويجب الالتزام به حرفياً عند بناء منطق التحقق (Validation) وقواعد الـ Unique.

## الخطوة التالية بعد هذه الوثيقة

بعد اعتماد هذه الوثيقة كمرجع نهائي، الخطوات المقترحة:
1. تصميم الـ Database Schema الفعلي (Migrations) استناداً لـ `01-entities.md`.
2. تصميم الـ Architecture العام (Controllers, Services, Policies).
3. خطة تنفيذ مرحلية (Sprint/Milestones).
4. البرمجة الفعلية.

> ملاحظة: هذه الوثيقة **لا تتضمن أي تفاصيل تقنية على مستوى الكود** (لا Migrations فعلية، لا Routes، لا Controllers) — فقط التحليل المنطقي الكامل. القرارات التقنية التفصيلية (نوع كل عمود بالضبط، الفهارس، إلخ) تُترك لمرحلة التصميم التقني التالية بناءً على هذه الوثيقة.
